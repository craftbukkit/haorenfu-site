# Security Policy

This repository contains the public website source code only. Production credentials, SSH keys, Tailscale configuration, cloud credentials, database secrets, backup credentials and private administration topology must never be committed here.

If you find a vulnerability, avoid publishing exploit details or real credentials in a public issue. Contact the repository owner privately or use GitHub's private vulnerability reporting feature when available.

Before deployment, review environment variables, dependency updates, authentication changes and any code that connects the public site to game-server or administration services.
